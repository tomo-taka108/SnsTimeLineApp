# learning — 学習・振り返りメモ

このフォルダは、開発を通じて理解を深めるために作成した**個人の学習用整理メモ**を格納する。
[docs/](../) 直下の設計書（要件定義・データモデル・API設計など）とは性質が異なり、
「仕組みを噛み砕いて理解する」「やった作業を振り返る」ことが目的。正式な設計の根拠は各設計書を参照。

いずれも **単体で開ける HTML**（ブラウザでダブルクリックで表示。ライト/ダーク両対応・オフライン閲覧可）。

## ファイル一覧

| ファイル | 内容 |
|---|---|
| [jwt-auth-basics.html](jwt-auth-basics.html) | **JWT認証の仕組み**。「入場券」のたとえでJWTの概念を押さえ、**アクセストークンとリフレッシュトークンをなぜ2種類に分けるのか**、セッション方式との違い、典型的なリスクと対策を整理。後半では実装した40ファイルを役割別に地図化し、ログイン1回の処理がどのファイルをどう通るかを追う。つまずきポイント集つき |
| [testing-basics.html](testing-basics.html) | **テストの考え方**。「手で確認していることをコードにやらせる」ところから始め、**テストの5段階（部品 → 機能 → 結合 → 画面 → E2E）**を図で整理。**なぜ層によって道具が変わるのか**（Mapper・Controller を単体テストできない理由）、**ブラックボックス／ホワイトボックス**の使い分け、ケースを機械的に洗い出す3技法（同値分割・境界値分析・デシジョンテーブル）、**Testcontainers と H2 の比較と選定理由**、テストが本当に落ちるかを確かめるミューテーションまで。つまずきポイント集つき |
