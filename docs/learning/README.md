# learning — 学習・振り返りメモ

このフォルダは、開発を通じて理解を深めるために作成した**個人の学習用整理メモ**を格納する。
[docs/](../) 直下の設計書（要件定義・データモデル・API設計など）とは性質が異なり、
「仕組みを噛み砕いて理解する」「やった作業を振り返る」ことが目的。正式な設計の根拠は各設計書を参照。

いずれも **単体で開ける HTML**（ブラウザでダブルクリックで表示。ライト/ダーク両対応・オフライン閲覧可）。
