# 用語集

本プロジェクトのドキュメント全体で使用する用語を統一するための対応表。
**ドキュメント・コード・DBのいずれにおいても、この表の名称を使う。**

## 命名の統一ルール

| ルール | 内容 |
|---|---|
| 日本語表記 | 本ドキュメント群で使う唯一の日本語名。ゆらぎを禁止する |
| 英語表記 | Javaのクラス名・変数名、APIのフィールド名（camelCase）に使う |
| DB名 | テーブル名・カラム名（snake_case、複数形） |

**特に禁止する表記ゆれ:**

| ✕ 使わない | ○ 使う | 理由 |
|---|---|---|
| ツイート / ポスト / つぶやき | **投稿** | X/Twitterのクローンではないため、独自の中立な用語に統一する |
| リツイート / リポスト | （**機能自体が対象外**） | [01_requirements.md](01_requirements.md) の対象外スコープを参照 |
| ファボ / お気に入り | **いいね** | |
| 返信 / リプライ | **コメント** | 本アプリのコメントは投稿とは別リソース。X の「リプライ＝投稿」とは異なる |
| フィード | **タイムライン** | |
| アカウント / メンバー | **ユーザー** | ただし「アカウント設定」画面名のみ例外的に許容 |

## 用語一覧

### ユーザー関連

| 日本語 | 英語 | DB名 | 説明 |
|---|---|---|---|
| ユーザー | User | `users` | 本アプリのアカウント。メールアドレスとパスワードで認証する |
| メールアドレス | Email | `users.email` | ログインIDを兼ねる。システム全体で一意 |
| ユーザー名 | Username | `users.username` | `@taro_123` のように表示される一意のハンドル。半角英数字とアンダースコアのみ |
| 表示名 | Display Name | `users.display_name` | 画面上に表示される名前。日本語可、重複可 |
| 自己紹介 | Bio | `users.bio` | プロフィールに表示する短い紹介文 |
| プロフィール画像 | Avatar | `users.avatar_file_id` | ユーザーのアイコン画像 |
| プロフィール | Profile | - | あるユーザーの情報と投稿一覧をまとめた表示単位 |

### 投稿関連

| 日本語 | 英語 | DB名 | 説明 |
|---|---|---|---|
| 投稿 | Post | `posts` | ユーザーが作成する本文＋画像のコンテンツ。本アプリの中心リソース |
| 本文 | Body | `posts.body` | 投稿のテキスト部分。最大280文字 |
| 投稿者 | Author | `posts.user_id` | 投稿を作成したユーザー |
| 添付画像 | Post Image | `post_images` | 投稿に紐づく画像。1投稿に複数枚を許容する構造 |
| 編集済み | Edited | `posts.edited_at` | 投稿後に本文が編集されたことを示す。値があればUIに「編集済み」を表示 |

### コメント・いいね関連

| 日本語 | 英語 | DB名 | 説明 |
|---|---|---|---|
| コメント | Comment | `comments` | 投稿に対して付ける短いテキスト。ネスト（コメントへのコメント）は不可 |
| コメント数 | Comment Count | `posts.comment_count` | ある投稿に付いたコメントの件数。非正規化カウンタとして保持する |
| いいね | Like | `likes` | 投稿に対する好意的な反応。1ユーザーにつき1投稿1回まで |
| いいね数 | Like Count | `posts.like_count` | ある投稿に付いたいいねの件数。非正規化カウンタとして保持する |
| いいね済み | Liked By Me | - | 閲覧中のユーザー自身がその投稿にいいねしているかの状態。APIレスポンスの `isLikedByMe` |

### フォロー関連

| 日本語 | 英語 | DB名 | 説明 |
|---|---|---|---|
| フォロー | Follow | `follows` | あるユーザーが別のユーザーの投稿を追う関係。一方向 |
| フォロワー | Follower | `follows.follower_id` | 「フォローする側」のユーザー |
| フォロイー | Followee | `follows.followee_id` | 「フォローされる側」のユーザー。日本語UIでは「フォロー中のユーザー」と表示する |
| フォロー中 | Following | - | 自分がフォローしているユーザーの集合。UIのラベルは「フォロー中」 |
| フォロワー一覧 | Followers | - | 自分をフォローしているユーザーの集合 |

> **注意**: `follower` と `followee` は綴りが1文字違いで取り違えやすい。
> DBのカラム名は必ず「`follower_id` がフォローする側／`followee_id` がフォローされる側」と覚える。

### タイムライン関連

| 日本語 | 英語 | DB名 | 説明 |
|---|---|---|---|
| タイムライン | Timeline | - | 投稿が新着順に並んだ一覧。DBテーブルは持たず `posts` から動的に生成する |
| 全体タイムライン | All Timeline | - | 全ユーザーの投稿を新着順に並べたもの。UIタブ名「すべて」 |
| フォロー中タイムライン | Following Timeline | - | 自分＋フォロー中ユーザーの投稿のみを新着順に並べたもの。UIタブ名「フォロー中」 |
| カーソル | Cursor | - | ページネーションで「どこまで読んだか」を示す不透明な文字列 |

### ファイル・画像関連

| 日本語 | 英語 | DB名 | 説明 |
|---|---|---|---|
| 保存ファイル | Stored File | `stored_files` | アップロードされたファイルのメタ情報。投稿画像とプロフィール画像で共用 |
| ストレージ種別 | Storage Type | `stored_files.storage_type` | 保存先の種類。`LOCAL` または `S3` |
| ストレージキー | Storage Key | `stored_files.storage_key` | 保存先内でファイルを一意に特定する相対パス。**絶対URLは保存しない** |

### 共通・設計用語

| 日本語 | 英語 | DB名 | 説明 |
|---|---|---|---|
| 論理削除 | Soft Delete | `deleted_at` | 行を物理的に消さず、削除日時を記録して非表示にする方式 |
| 物理削除 | Hard Delete | - | 行を実際に `DELETE` する方式。本アプリでは `likes` / `follows` に適用 |
| 非正規化カウンタ | Denormalized Counter | `like_count` 等 | 集計結果を親テーブルのカラムに持たせて高速化する手法 |
| 冪等 | Idempotent | - | 同じ操作を何回実行しても結果が変わらない性質。いいね・フォローAPIに適用 |
| 機能ID | Feature ID | - | `F-PO-01` 形式の識別子。全ドキュメントを横断する一次キー |
| 画面ID | Screen ID | - | `SC-03` 形式の識別子 |
| MVP | Minimum Viable Product | - | アプリとして最小限成立する機能集合。[02_feature_list.md](02_feature_list.md) 参照 |

## 対象外機能の用語（誤って設計に混入させないための明示）

以下は**本アプリで実装しない**概念。ドキュメント内で言及する場合は必ず「対象外」と併記すること。

| 用語 | 説明 | 対象外とした理由 |
|---|---|---|
| インプレッション数 | 投稿が表示された回数 | X/Twitterとの差別化ポイント。閲覧数を可視化しない方針 |
| リツイート / リポスト | 他人の投稿を自分のタイムラインに再共有する機能 | 差別化ポイント。投稿の引用・再共有は行わない |
| ハッシュタグ | `#タグ` による投稿の分類 | 学習ゴールの範囲外 |
| ダイレクトメッセージ | ユーザー間の1対1のやりとり | 学習ゴールの範囲外 |
| 通知 | いいね・コメント・フォローの通知 | Phase3候補 |
| ブロック / ミュート | 特定ユーザーの非表示 | Phase3候補 |
