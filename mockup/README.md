# 画面モックアップ

[docs/03_screen_design.md](../docs/03_screen_design.md) で定義した画面を、**HTML / CSS / JavaScript だけ**で再現した静的プロトタイプ。

> **これはモックアップであり、実装ではありません。**
> DBもサーバーも使わず、すべてブラウザ内で完結します。表示されるデータはすべてダミーです。

---

## 開き方

ビルドもサーバーも不要。**HTMLファイルをブラウザで直接開く**だけ。

```bash
start mockup/timeline.html          # Windows
open  mockup/timeline.html          # macOS
```

まず [`timeline.html`](timeline.html) から見るのがおすすめです。ヘッダーやカードのリンクから各画面へ移動できます。

## 実際に動くところ

静的HTMLですが、**設計の要点になっている挙動はJavaScriptで実際に動きます**。

| 動き | 確認できる画面 | 対応機能 |
|---|---|---|
| **いいねの楽観的更新** — 押した瞬間に数字と塗りつぶしが変わる。**連打しても2にならない（冪等）** | SC-03 / SC-04 | F-LK-01, F-LK-02 |
| **タブ切替** — 「すべて」↔「フォロー中」。**URLの `?tab=` に反映**される | SC-03 | F-TL-01, F-TL-02 |
| **無限スクロール** — 下端手前で次を読み込み、末尾に「これ以上投稿はありません」 | SC-03 | F-TL-03 |
| **フォローのトグル** — 「フォロー」↔「フォロー中」。**ホバーで「フォロー解除」（赤）** | SC-05 / 一覧系 | F-FL-01, F-FL-02 |
| **文字数カウンタ** — 残り20文字で警告色、**超過で赤＋投稿ボタン無効化** | MD-01 / SC-04 | F-PO-01, F-CM-01 |
| **モーダル** — 背景クリックとESCで閉じる | 全画面 | MD-01〜03 |
| **投稿の即時反映** — 投稿するとタイムライン先頭に挿入される | SC-03 | F-PO-01 |
| **コメントの即時反映** — 送信すると一覧末尾に追加され、コメント数が+1 | SC-04 | F-CM-01 |
| **検索のデバウンス** — 入力後300ms待って検索。**未入力では検索しない** | SC-07 | F-US-05 |
| **保存ボタンの無効化** — 変更がないと押せない | SC-06 | F-US-03 |
| **トースト** — 画面下部に出て3秒で消える | 全画面 | F-CO-01 |

## 差別化ポイントの確認

本アプリがX/Twitterと明確に違う点を、モック上でも徹底しています。

- ✅ 投稿カードのアクション行は**「コメント」と「いいね」の2つだけ**
- ❌ **インプレッション数（閲覧数）はどこにも表示しない**
- ❌ **リツイート / リポストのボタンはどこにも置かない**

機械的に確認するには次を実行します（**1件もヒットしないこと**が正しい状態）。

```bash
grep -riE "インプレッション|リツイート|リポスト|閲覧数|ツイート|ファボ|リプライ" mockup/ --include=*.html --include=*.js --include=*.css
```

用語は [docs/08_glossary.md](../docs/08_glossary.md) に従い、「投稿」「いいね」「コメント」「タイムライン」で統一しています。

## 実装との関係

| 項目 | モック | 実装（予定） |
|---|---|---|
| 技術 | 素のHTML / CSS / JS | React (SPA) + Vite |
| データ | `mock.js` 内のダミー配列 | REST API + PostgreSQL |
| 画像 | CSSグラデーションで代替 | アップロードした実画像（S3） |
| 画面遷移 | 別HTMLファイルへのリンク | React Router |

**モックはあくまで見た目と操作感の検証用**であり、実装時にはReactで作り直します。
このモックの役割は、**実装に入る前にUXの穴を見つけること**です。

## 補足

- **ダミーデータのメールアドレスは `example.com` のみ**を使っています（[CLAUDE.md](../CLAUDE.md) 6章）
- 添付画像は**CSSグラデーションで代替**しています。外部通信が発生しないため、オフラインでも崩れません
- 一部の画面では、エラー表示の見た目を確認できるよう**エラー状態を常時表示**しています（各画面の「モック補足」に明記）
- レスポンシブ対応済み。ブラウザ幅を767px以下にすると1カラム＋FAB固定の表示になります
